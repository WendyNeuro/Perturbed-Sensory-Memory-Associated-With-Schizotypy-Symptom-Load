# Perturbed-Sensory-Memory-Associated-With-Schizotypy-Symptom-Load
We used a simple odd-ball pitch-deviant paradigm and compared ERP (i.e., N100 and MMN) amplitudes and latencies across a sample of healthy participants who completed the Schizophrenia Personality Questionnaire - Brief Revised (SPQ-BR).<br><br> 
Repository holds analysis scripts, stimuli, and Dropbox link to data.<br><br> 
Published: Torrens, W. A., Pablo, N. J., Haigh, S. M., & Berryhill, M. E. (2026). Perturbed sensory memory associated with schizotypy symptom load. Schizophrenia Research. https://doi.org/10.1016/j.schres.2025.12.001<br><br>
